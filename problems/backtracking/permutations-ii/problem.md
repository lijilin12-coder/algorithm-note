# 全排列 II

## 题目描述

给定一个可能包含重复数字的数组 `nums`，请你用回溯法找出所有不重复的全排
列，并按照下面规定的顺序输出。

## 输入格式

第一行一个整数 `n`，表示 `nums` 的长度。

第二行 `n` 个整数，即 `nums`（可能含重复数字，不保证有序）。

## 输出格式

第一行输出不重复排列的总数。

接下来按照下面规定的回溯顺序输出每一种排列：先把 `nums` 从小到大排序，
用一个布尔数组 `used` 记录每个下标当前是否已经被用在当前排列中。递归函数
`backtrack(path)` 每次让下标 `i` 从 `0` 到 `n-1` 依次尝试：

- 如果 `used[i]` 为真，跳过（已经用过）。
- 如果 `i > 0` 且 `nums[i] == nums[i-1]` 且 `used[i-1]` 为假，说明同一层
  已经尝试过相同的值却还未选中它，跳过当前下标以避免产生重复排列。
- 否则把 `nums[i]` 加入 `path`，标记 `used[i] = true`，递归调用
  `backtrack(path)`，返回后把 `nums[i]` 移出 `path` 并将 `used[i]` 置回
  假（回溯）。

当 `path` 的大小等于 `n` 时输出当前排列并返回。

按照这个规则，输出的排列恰好是所有不重复排列按字典序从小到大排列的结果。
每种排列占一行，`n` 个数按顺序用空格分隔。

## 样例

输入：
```
3
1 1 2
```

输出：
```
3
1 1 2
1 2 1
2 1 1
```

## 数据范围

- `1 <= n <= 8`
- `-10 <= nums[i] <= 10`

## 提示

- 先把 `nums` 排序，重复值就会相邻，方便剪枝去重。
- 用 `used` 数组代替“移除元素再插回”的方式，标记每个下标是否已经在当前
  排列中被选用。
- 去重的关键在于：同一层递归中，如果前一个相同的值还没被选中（`!used[i-1]`），
  就不能跳过它去选后一个相同的值，否则会产生重复排列。
- 当 `path.size() == nums.size()` 时输出并返回，不再继续深入。
