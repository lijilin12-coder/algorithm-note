# 组合

## 题目描述

给定两个整数 `n` 和 `k`，请你用回溯法找出并输出从 `1` 到 `n` 中所有可能的
`k` 个数的组合，并按照下面规定的顺序输出。

## 输入格式

一行两个整数 `n` 和 `k`。

## 输出格式

第一行输出组合总数（应为 $C_n^k$）。

接下来按照“从小到大依次尝试每个起点，只允许后面的数递增选取”的回溯顺序，
输出每一种组合：每种组合占一行，`k` 个数按从小到大的顺序、用空格分隔。

## 样例

输入：
```
4 2
```

输出：
```
6
1 2
1 3
1 4
2 3
2 4
3 4
```

## 数据范围

- `1 <= n <= 20`
- `1 <= k <= n`

## 提示

- 用 `path` 保存当前已选择的数，递归函数 `backtrack(start)` 表示“下一个可以
  选择的数是 `start`”。
- 当 `path` 的大小等于 `k` 时，说明凑够了一组，输出后返回，不再继续往下选。
- 否则用一个循环，让 `i` 从 `start` 到 `n`：把 `i` 加入 `path`，递归调用
  `backtrack(i + 1)`，再把 `i` 从 `path` 中移除（回溯）。
- 和“子集”不同的是，这里只有 `path` 大小恰好等于 `k` 时才输出，不是每个节点
  都输出。
