# 解数独（Sudoku Solver）

来源：[LeetCode 37. 解数独](https://leetcode.cn/problems/sudoku-solver/description/)

## 题目描述

编写一个程序，通过填充空白单元格来解决数独问题。

数独的规则如下：

1. 数字 `1-9` 在每一行只能出现一次。
2. 数字 `1-9` 在每一列只能出现一次。
3. 数字 `1-9` 在每一个以粗实线分隔的 `3x3` 宫内只能出现一次。

输入中的数独网格保证有**唯一解**。

## 输入格式

九行，每行九个字符，表示数独网格：

- 数字 `1-9` 表示已填入的数字；
- `.` 表示空白单元格，需要你来填充。

## 输出格式

九行，每行九个字符，表示填完后的数独网格（数字之间不留空格）。

## 样例

输入：
```
53..7....
6..195...
.98....6.
8...6...3
4..8.3..1
7...2...6
.6....28.
...419..5
....8..79
```

输出：
```
534678912
672195348
198342567
859761423
426853791
713924856
961537284
287419635
345286179
```

## 数据范围

- 网格固定为 `9 x 9`
- `board[i][j]` 是字符 `'1'` 到 `'9'` 或 `'.'`
- 输入的数独保证有唯一解

## 提示

- 这是回溯法的经典应用：找一个空格，依次尝试填入 `1-9`，
  每次填入后检查是否违反数独规则（行、列、宫各不重复）；
  合法就继续找下一个空格，不合法就换下一个数字；
  所有空格都填满时得到答案；走不通就撤销上一步（回溯）。
- 可以用三个布尔数组分别记录每行、每列、每个宫已经出现了哪些数字，
  这样合法性检查就是 `O(1)`。
- 思考一下：如何快速判断某个格子属于哪一个 `3x3` 宫？
