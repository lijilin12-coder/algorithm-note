注意特征：带分数中，数字 `1~9` 分别出现且只出现一次（不包含 `0`）。

类似这样的带分数，`100` 有 `11` 种表示法。

## 输入格式

一个正整数 `N`。

## 输出格式

输出输入数字用数码 `1~9` 不重复不遗漏地组成带分数表示的全部种数。

## 样例

输入 1：
```
100
```

输出 1：
```
11
```

输入 2：
```
105
```

输出 2：
```
6
```

## 数据范围

- `1 <= N < 10^6`

## 提示

- 一个「带分数」写成 `A + B/C` 的形式，其中 `A`、`B`、`C` 三段数字合起来恰好是
  `1~9` 这 `9` 个数字的一个排列（每个数字出现且只出现一次，`A`、`B`、`C` 各自
  的位数都 `>= 1`）。注意 `B/C` 不要求是真分数（即不要求 `B < C`），例如样例
  里 `69258/714` 本身恰好等于整数 `97`。
- 枚举思路：枚举 `1~9` 的全排列（`9! = 362880` 种，数据规模很小，直接枚举即可），
  对每个排列再枚举切分点，把它切成三段分别作为 `A`、`B`、`C` 的数字；`A` 至少
  占 `1` 位、最多占 `7` 位（因为 `B`、`C` 也各自至少要留 `1` 位）。
- 判断 `A + B/C == N` 时不要用浮点数除法（会有精度误差），应改成判断整数等式
  `A*C + B == N*C` 是否成立；注意 `A`、`B`、`C`、`N` 相乘可能超过 `int` 范围，
  要用 `long long`。
- 剪枝：`A` 的位数越多，`A` 的值只会越来越大（因为每一位数字都是 `1~9`，不会
  出现前导零），所以一旦当前 `A` 已经超过 `N`，这个排列下更长的 `A` 也不可能
  满足要求，可以直接跳过，不用再枚举更长的 `A`。
