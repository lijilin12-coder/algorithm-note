# 组合总和 II

## 题目描述

给定一个可能包含重复数字的数组 `candidates` 和一个目标数 `target`，请你用回
溯法找出所有和等于 `target` 的组合。`candidates` 中的每个数字在每个组合中
只能使用一次，解集中不能包含重复的组合，并按照下面规定的顺序输出。

## 输入格式

第一行两个整数 `n` 和 `target`，`n` 是 `candidates` 的长度。

第二行 `n` 个整数，即 `candidates`，用空格分隔（可能含重复数字，且不保证
有序）。

## 输出格式

第一行输出组合总数。

接下来按照下面规定的回溯顺序输出每一种组合：先把 `candidates` 从小到大排
序，然后从下标 `0` 开始依次尝试每个数作为当前组合的下一个数（同一层遇到与
上一个尝试过的数相同的值要跳过，避免重复组合），当剩余目标减到 `0` 时输出
当前组合。

每种组合占一行，格式为：组合大小 `k`，后面跟 `k` 个数（从小到大排列），用
空格分隔。

## 样例

输入：
```
7 8
10 1 2 7 6 1 5
```

输出：
```
4
3 1 1 6
3 1 2 5
2 1 7
2 2 6
```

## 数据范围

- `1 <= n <= 20`
- `1 <= candidates[i] <= 50`
- `1 <= target <= 30`

## 提示

- 先把 `candidates` 排序，方便剪枝和去重。
- 递归函数 `backtrack(start, remain)` 表示“下一个可以考虑的下标是
  `start`，还需要凑出 `remain`”。
- 当 `remain == 0` 时，输出当前 `path` 并返回。
- 用一个循环，让 `i` 从 `start` 到 `n-1`：
  - 如果 `candidates[i] > remain`，因为已经排过序，后面的数只会更大，可以
    直接结束循环（剪枝）。
  - 如果 `i > start` 且 `candidates[i] == candidates[i-1]`，说明同一层已经
    用过相同的数字，跳过它以避免产生重复组合。
  - 否则把 `candidates[i]` 加入 `path`，递归调用
    `backtrack(i + 1, remain - candidates[i])`，再把它移除（回溯）。
