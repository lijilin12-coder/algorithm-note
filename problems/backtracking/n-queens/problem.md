# N 皇后

## 题目描述

在 `n x n` 的棋盘上摆放 `n` 个皇后，要求任意两个皇后都不能互相攻击，即任意两个
皇后不能位于同一行、同一列，也不能位于同一条对角线上。

请你用回溯法求出所有摆法，并按照下面规定的顺序输出。

## 输入格式

一行一个整数 `n`。

## 输出格式

第一行输出方案总数。

接下来按照“从第 0 行开始，每一行依次尝试从第 0 列到第 `n-1` 列摆放皇后”的
回溯顺序，依次输出每一种摆法：每种摆法占 `n` 行，每行是一个长度为 `n` 的字符
串，`Q` 表示皇后，`.` 表示空位；相邻两种摆法之间输出一个空行。

如果不存在合法摆法，只输出方案总数 `0`，不输出任何棋盘。

## 样例

输入：
```
4
```

输出：
```
2
.Q..
...Q
Q...
..Q.

..Q.
Q...
...Q
.Q..
```

## 数据范围

- `1 <= n <= 9`

## 提示

- 按行递归：对第 `row` 行，依次尝试把皇后放在第 `0` 到 `n-1` 列，检查是否与
  之前已摆放的皇后冲突（同列，或 `|行差| == |列差|` 表示同对角线）。
- 用一个数组 `col[row]` 记录第 `row` 行皇后所在的列，方便检查冲突和最终输出。
- 摆满 `n` 行（`row == n`）时，说明找到一种合法摆法，输出当前棋盘后继续回溯
  寻找下一种。
- 记得回溯：递归返回后要撤销当前行的摆放，尝试下一列。
