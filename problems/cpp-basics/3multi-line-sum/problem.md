# 多组输入求和

## 题目描述

不断读取两个整数 `a` 和 `b`，直到输入结束（EOF）为止。对每一组输入，输出 `a + b`
的结果。

## 输入格式

多行，每行包含两个整数 `a` 和 `b`，用空格分隔。输入直到文件结束。

## 输出格式

对每一组输入，输出一行，为 `a + b` 的结果。

## 样例

输入：
```
1 2
3 4
10 -5
```

输出：
```
3
7
5
```

## 数据范围

- 输入组数不超过 `10^4`
- `-10^9 <= a, b <= 10^9`

## 提示

使用 `while (cin >> a >> b)` 可以不断读取输入，直到输入结束（EOF）时循环自动终止。
