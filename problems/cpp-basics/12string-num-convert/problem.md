# 字符串与数字互相转换

## 题目描述

给定 `n` 个数字字符串，每个字符串表示一个整数，请你把它们转换成整数求和，
再把结果转换回字符串输出。

## 输入格式

第一行：整数 `n`。
第二行：`n` 个字符串，用空格分隔，每个字符串都是一个整数（可能带负号）。

## 输出格式

一行，求和结果（以字符串形式输出）。

## 样例

输入：
```
3
1 2 3
```

输出：
```
6
```

## 数据范围

- `1 <= n <= 1000`
- 每个数的绝对值不超过 `10^6`。

## 提示

- 用 `stoi(str)` 把字符串转成 `int`。
- 用 `to_string(n)` 把 `int` 转回字符串。
