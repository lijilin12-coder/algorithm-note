# 逆序输出 vector

## 题目描述

给定 `n` 个整数，请你用 `vector` 存储它们，将其逆序后输出。

## 输入格式

第一行一个整数 `n`。

第二行 `n` 个整数，用空格分隔。

## 输出格式

一行，`n` 个整数，为原序列逆序后的结果，用空格分隔。

## 样例

输入：
```
5
1 2 3 4 5
```

输出：
```
5 4 3 2 1
```

## 数据范围

- `1 <= n <= 1000`
- `-1000 <= 每个数 <= 1000`

## 提示

- 用 `vector<int>` 读入数据后，调用 `reverse(v.begin(), v.end())` 原地反转。
- 反转后用范围 for 依次输出，数字之间用空格分隔。
