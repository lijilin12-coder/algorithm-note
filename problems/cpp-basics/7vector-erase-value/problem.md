# 删除 vector 中等于某个值的元素

## 题目描述

给定 `n` 个整数和一个目标值 `target`，请你用 `vector` 存储这些数，删除其中所有
等于 `target` 的元素，输出删除后剩余的元素。

## 输入格式

第一行两个整数 `n` 和 `target`。

第二行 `n` 个整数，用空格分隔。

## 输出格式

一行，删除所有等于 `target` 的元素后剩余的元素，按原顺序输出，用空格分隔。
如果全部元素都被删除，输出一个空行。

## 样例

输入：
```
5 2
1 2 3 2 5
```

输出：
```
1 3 5
```

## 数据范围

- `1 <= n <= 1000`
- `-1000 <= 每个数, target <= 1000`

## 提示

- 用 remove-erase 写法一次性删除所有等于 `target` 的元素：
  `v.erase(remove(v.begin(), v.end(), target), v.end());`
- `remove` 需要 `#include <algorithm>`。
