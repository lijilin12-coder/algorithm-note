# 查找元素第一次出现的下标

## 题目描述

给定 `n` 个整数和一个目标值 `target`，请你用 `vector` 存储这些数，找出
`target` 在序列中第一次出现的下标（从 `0` 开始）。如果 `target` 不存在，输出
`-1`。

## 输入格式

第一行两个整数 `n` 和 `target`。

第二行 `n` 个整数，用空格分隔。

## 输出格式

一行，一个整数：`target` 第一次出现的下标，不存在则输出 `-1`。

## 样例

输入：
```
5 3
1 2 3 4 3
```

输出：
```
2
```

## 数据范围

- `1 <= n <= 1000`
- `-1000 <= 每个数, target <= 1000`

## 提示

- 用 `find(v.begin(), v.end(), target)` 查找元素，返回一个迭代器。
- 如果返回的迭代器等于 `v.end()`，说明没找到，输出 `-1`。
- 否则用 `it - v.begin()` 计算下标。
