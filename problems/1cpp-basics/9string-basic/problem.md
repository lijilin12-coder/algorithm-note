# 字符串的拼接与比较

## 题目描述

给定两个字符串 `a` 和 `b`（不含空格），请你输出它们拼接后的结果、各自的长度，
以及按字典序比较的结果。

## 输入格式

两行，每行一个字符串。

## 输出格式

第一行：`a` 和 `b` 拼接后的字符串（`a + b`）。
第二行：`a` 的长度和 `b` 的长度，用空格分隔。
第三行：比较结果，`a == b` 输出 `equal`，`a < b` 输出 `less`，否则输出 `greater`。

## 样例

输入：
```
abc
abd
```

输出：
```
abcabd
3 3
less
```

## 数据范围

- 字符串长度不超过 `1000`，只包含大小写字母。

## 提示

- 用 `+` 拼接字符串，`size()`（或 `length()`）取长度。
- 字符串可以直接用 `==`、`<` 比较，按字典序逐字符比较。
