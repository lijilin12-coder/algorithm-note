# vector 求和与最大值

## 题目描述

给定 `n` 个整数，请你用 `vector` 存储它们，并输出这 `n` 个数的和与最大值。

## 输入格式

第一行一个整数 `n`。

第二行 `n` 个整数，用空格分隔。

## 输出格式

一行，两个整数：这 `n` 个数的和与最大值，用空格分隔。

## 样例

输入：
```
5
3 1 4 1 5
```

输出：
```
14 5
```

## 数据范围

- `1 <= n <= 1000`
- `-1000 <= 每个数 <= 1000`

## 提示

- 用 `vector<int> v(n)` 或循环 `push_back` 读入数据。
- 求和可以用 `accumulate(v.begin(), v.end(), 0)`。
- 最大值可以用 `*max_element(v.begin(), v.end())`。
