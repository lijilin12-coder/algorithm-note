# 对 vector 排序后输出

## 题目描述

不断读取整数，直到输入结束（EOF）为止。请你用 `vector` 存储这些数，将其从小到
大排序后输出。

## 输入格式

若干个整数，用空格或换行分隔，直到输入结束。

## 输出格式

一行，排序后的所有整数，用空格分隔。

## 样例

输入：
```
5 3 1 4 2
```

输出：
```
1 2 3 4 5
```

## 数据范围

- 整数个数不超过 `10^4`
- `-10^9 <= 每个数 <= 10^9`

## 提示

- 用 `while (cin >> x) v.push_back(x);` 读入所有数据。
- 调用 `sort(v.begin(), v.end())` 从小到大排序。
