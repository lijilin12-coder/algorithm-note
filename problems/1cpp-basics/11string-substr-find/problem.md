# 截取子串与查找子串位置

## 题目描述

给定字符串 `s`、整数 `len` 和子串 `t`，请你输出 `s` 的前 `len` 个字符，以及
`t` 在 `s` 中第一次出现的下标（从 `0` 开始）。如果 `t` 不在 `s` 中出现，输出
`-1`。

## 输入格式

第一行：字符串 `s`。
第二行：整数 `len`。
第三行：字符串 `t`。

## 输出格式

第一行：`s` 的前 `len` 个字符。
第二行：`t` 在 `s` 中第一次出现的下标，不存在则输出 `-1`。

## 样例

输入：
```
HelloWorld
5
World
```

输出：
```
Hello
5
```

## 数据范围

- 字符串长度不超过 `1000`，只包含大小写字母。
- `0 <= len <= s 的长度`

## 提示

- 用 `s.substr(0, len)` 截取前 `len` 个字符。
- 用 `s.find(t)` 查找子串首次出现的位置，找不到时返回的是 `string::npos`，
  不是 `-1`，需要单独判断后再输出 `-1`。
