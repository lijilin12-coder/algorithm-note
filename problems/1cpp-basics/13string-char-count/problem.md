# 统计数字字符和字母字符个数

## 题目描述

给定一行字符串 `s`（可能包含字母、数字和其他符号，也可能包含空格），请你
统计其中数字字符（`0`-`9`）和字母字符（大小写不限）的个数。

## 输入格式

一行，字符串 `s`（用 `getline` 读入，可能包含空格，也可能是空行）。

## 输出格式

一行，两个整数：数字字符个数和字母字符个数，用空格分隔。

## 样例

输入：
```
abc123 XYZ!
```

输出：
```
3 6
```

## 数据范围

- 字符串长度不超过 `1000`。

## 提示

- `<cctype>` 提供的 `isdigit`、`isalpha` 分别判断字符是不是数字、字母。
- 这两个函数的参数类型是 `int`，直接传 `char` 在字符值为负时是未定义行为，
  稳妥的写法是先转成 `unsigned char` 再传入：`isdigit((unsigned char)c)`。
