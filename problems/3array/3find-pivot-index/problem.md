# 寻找数组的中心下标（Find Pivot Index）

> LeetCode: [724. Find Pivot Index](https://leetcode.com/problems/find-pivot-index/) / [724. 寻找数组的中心下标](https://leetcode.cn/problems/find-pivot-index/description/)

## 题目描述

给你一个整数数组 `nums`，请计算数组的**中心下标**。

数组**中心下标**是数组的一个下标，其**左侧所有元素相加的和**等于**右侧所有元素相加的和**。

- 如果中心下标位于数组最左端，那么左侧数之和视为 `0`（因为下标的左侧不存在元素）。
  这一点对于中心下标位于数组最右端同样适用。
- 如果数组有**多个**中心下标，应该返回**最靠近左边**的那一个。
- 如果数组**不存在**中心下标，返回 `-1`。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数，用空格分隔，表示数组 `nums`。

## 输出格式

一行一个整数：中心下标；若不存在则输出 `-1`。

## 样例

输入：
```
6
1 7 3 6 5 6
```

输出：
```
3
```

解释：中心下标是 `3`。左侧数之和 `= nums[0] + nums[1] + nums[2] = 1 + 7 + 3 = 11`，
右侧数之和 `= nums[4] + nums[5] = 5 + 6 = 11`，二者相等。

## 数据范围

- `1 <= nums.length <= 10^4`
- `-1000 <= nums[i] <= 1000`

## 提示

- 暴力做法对每个下标都分别求左侧和、右侧和，时间复杂度 `O(n^2)`。
- 更优的做法只遍历一次：先求出整个数组的总和 `total`，然后从左往右累加 `leftSum`，
  此时右侧和就是 `total - leftSum - nums[i]`。当 `leftSum == total - leftSum - nums[i]`
  （等价于 `2 * leftSum + nums[i] == total`）时，`i` 就是中心下标。整体 `O(n)`。
- 注意元素可能为负数，且要返回**最靠左**的中心下标，所以找到第一个满足条件的就立即返回。
