# 矩阵区域和（Matrix Block Sum）

> LeetCode: [1314. Matrix Block Sum](https://leetcode.com/problems/matrix-block-sum/) / [1314. 矩阵区域和](https://leetcode.cn/problems/matrix-block-sum/)

## 题目描述

给你一个 `m x n` 的矩阵 `mat` 和一个整数 `k`，请你返回一个矩阵 `answer`，其中每个
`answer[i][j]` 是所有满足下述条件的元素 `mat[r][c]` 的和：

- `i - k <= r <= i + k`
- `j - k <= c <= j + k`
- `(r, c)` 在矩阵内。

换句话说，`answer[i][j]` 是以 `(i, j)` 为中心、向上下左右各扩展 `k` 格所形成的矩形
区域内所有元素的和（超出矩阵边界的部分忽略）。

## 输入格式

第一行两个整数 `m n`，表示矩阵的行数和列数。

接下来 `m` 行，每行 `n` 个整数，用空格分隔，表示矩阵 `mat`。

最后一行一个整数 `k`。

## 输出格式

`m` 行，每行 `n` 个整数，用空格分隔，表示结果矩阵 `answer`。

## 样例

输入：
```
3 3
1 2 3
4 5 6
7 8 9
1
```

输出：
```
12 21 16
27 45 33
24 39 28
```

解释：以 `(0, 0)` 为中心、`k = 1` 的区域覆盖 `mat[0..1][0..1]`，即
`1 + 2 + 4 + 5 = 12`；其余格子同理。

## 数据范围

- `1 <= m, n, k <= 100`
- `1 <= mat[i][j] <= 100`

## 提示

- 暴力做法对每个格子都遍历它周围 `(2k+1) x (2k+1)` 的区域求和，时间复杂度
  `O(m * n * k^2)`，在本题数据范围内也能通过，但不够优雅。
- 更优的做法是**二维前缀和**：先构造前缀和数组 `dp[i][j]` 表示从左上角 `(0, 0)`
  到 `(i, j)` 的矩形和，这样任意矩形的和都能用容斥原理 `O(1)` 求出，整体
  `O(m * n)`。
- 注意区域边界要夹在矩阵范围内：`r1 = max(i-k, 0)`、`r2 = min(i+k, m-1)`，列同理。
