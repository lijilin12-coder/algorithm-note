# 连续数组（Contiguous Array）

> LeetCode: [525. Contiguous Array](https://leetcode.com/problems/contiguous-array/) / [525. 连续数组](https://leetcode.cn/problems/contiguous-array/description/)

## 题目描述

给定一个二进制数组 `nums`，找到含有**相同数量的 `0` 和 `1`** 的最长连续子数组，并返回该子数组的**长度**。

## 输入格式

第一行一个整数 `n`，表示数组长度。

第二行 `n` 个整数，用空格分隔，每个数不是 `0` 就是 `1`。

## 输出格式

一行一个整数：满足条件的最长连续子数组的长度；若不存在则输出 `0`。

## 样例

输入：
```
9
0 1 1 1 1 1 0 0 0
```

输出：
```
6
```

解释：子数组 `[1, 1, 1, 0, 0, 0]`（下标 `3..8`）含有 3 个 `1` 和 3 个 `0`，是满足条件
的最长连续子数组，长度为 `6`。

## 数据范围

- `1 <= nums.length <= 10^5`
- `nums[i]` 不是 `0` 就是 `1`

## 提示

- 暴力做法枚举所有子数组、统计其中 `0` 和 `1` 的个数，时间复杂度 `O(n^2)`，会超时。
- **关键转换**：把 `0` 看成 `-1`，那么「`0` 和 `1` 数量相等」就等价于「这段子数组的
  **和为 0**」。问题转化为求**和为 0 的最长子数组**。
- 结合**前缀和 + 哈希表**：记 `prefix[i]` 为前 `i` 个数的和。若 `prefix[i] == prefix[j]`
  （`i > j`），则子数组 `j+1..i` 的和为 0，长度为 `i - j`。用哈希表记录每个前缀和**第一次**
  出现的下标，遍历时若当前前缀和已出现过，就用 `当前下标 - 首次下标` 更新答案。
- 小技巧：初始化时把前缀和 `0` 对应下标 `-1` 存入哈希表，这样从数组开头就和为 0 的情况
  也能被统一处理，无需特判。
