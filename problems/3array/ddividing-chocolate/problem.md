# 1227. 分巧克力

- [题目](https://www.acwing.com/problem/content/description/1229/)

## 题目描述

儿童节那天有 `K` 位小朋友到小明家做客。

小明拿出了珍藏的巧克力招待小朋友们。

小明一共有 `N` 块巧克力，其中第 `i` 块是 `Hi x Wi` 的方格组成的长方形。

为了公平起见，小明需要从这 `N` 块巧克力中切出 `K` 块巧克力分给小朋友们。

切出的巧克力需要满足：

1. 形状是正方形，边长是整数
2. 大小相同

例如一块 `6x5` 的巧克力可以切出 `6` 块 `2x2` 的巧克力或者 `2` 块 `3x3` 的巧克力。

当然小朋友们都希望得到的巧克力尽可能大，你能帮小明计算出最大的边长是多少么？

## 输入格式

第一行包含两个整数 `N` 和 `K`。

以下 `N` 行每行包含两个整数 `Hi` 和 `Wi`。

输入保证每位小朋友至少能获得一块 `1x1` 的巧克力。

## 输出格式

输出切出的正方形巧克力最大可能的边长。

## 数据范围

`1 <= N, K <= 10^5`

`1 <= Hi, Wi <= 10^5`

## 样例

输入：
```
2 10
6 5
5 6
```

输出：
```
2
```

## 提示

- 设切出的正方形边长为 `x`，则第 `i` 块巧克力最多能切出
  `floor(Hi / x) * floor(Wi / x)` 块边长为 `x` 的正方形。
- **单调性**：`x` 越大，每块巧克力能切出的数量越少，总数量关于 `x` 单调不增。
  因此“能否切出至少 `K` 块边长为 `x` 的正方形”是关于 `x` 的一个单调判定，
  满足二分答案的条件。
- 二分候选边长 `x`（范围 `[1, min(max(Hi), max(Wi))]`），对每个 `x` 累加所有
  巧克力能切出的数量 `sum`，若 `sum >= K` 则 `x` 可行，尝试更大的 `x`；否则
  尝试更小的 `x`。
- 注意 `sum` 可能超过 `int` 范围（`N` 和单块数量都可达 `10^5` 级别），累加时
  用 `long long`，或者一旦 `sum >= K` 就提前结束当前判定的累加。
- 题目保证每位小朋友至少能分到 `1x1` 的巧克力，所以二分下界 `1` 一定可行，
  不需要特判无解的情况。
