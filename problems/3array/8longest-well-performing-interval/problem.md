# 表现良好的最长时间段（Longest Well-Performing Interval）

> LeetCode: [1124. Longest Well-Performing Interval](https://leetcode.com/problems/longest-well-performing-interval/) / [1124. 表现良好的最长时间段](https://leetcode.cn/problems/longest-well-performing-interval/)

## 题目描述

给你一份工作时间表 `hours`，表示某公司员工每天的工作小时数。

我们认为当员工一天中的工作小时数**大于 `8`** 小时的时候，那么这一天就是「劳累的一天」。

所谓「表现良好的时间段」，意味着在这段时间内，「劳累的天数」是严格**大于**「不劳
累的天数」。

请你返回「表现良好时间段」的最大长度。

## 输入格式

第一行一个整数 `n`，表示天数。

第二行 `n` 个整数，用空格分隔，表示 `hours`。

## 输出格式

一行一个整数：表现良好时间段的最大长度；若不存在则输出 `0`。

## 样例

输入：
```
7
9 9 6 0 6 6 9
```

输出：
```
3
```

解释：最长表现良好时间段是下标 `0..2`（`[9, 9, 6]`），有 `2` 个劳累的天数，`1` 个
不劳累的天数，满足条件，长度为 `3`。

## 数据范围

- `1 <= hours.length <= 10^4`
- `0 <= hours[i] <= 16`

## 提示

- **关键转换**：把每一天转成 `+1`（劳累，`hours[i] > 8`）或 `-1`（不劳累），那么
  「劳累天数 > 不劳累天数」就等价于「这段子数组的**和大于 0**」。问题转化为求
  **和大于 0 的最长子数组**。
- 结合**前缀和 + 哈希表**：记 `prefix[i]` 为前 `i` 个数的和。
  - 如果 `prefix[i] > 0`，说明从开头到第 `i` 天整体就是表现良好的，可以直接
    用 `i` 更新答案。
  - 否则，想找一个更早的位置 `j`，使得 `prefix[i] - prefix[j] > 0`，即
    `prefix[j] < prefix[i]`。由于 `prefix` 每次变化只有 `±1`，只需要检查
    `prefix[j] == prefix[i] - 1` 是否出现过即可，若出现过，用 `i - j` 更新答案。
- 哈希表中对每个前缀和值**只记录第一次出现的下标**（这样差值最大，得到的子数组
  最长），后续出现相同前缀和时不要覆盖。
- 与 [6contiguous-array](../6contiguous-array/problem.md) 思路一致，都是「前缀和 +
  哈希表，只记录首次出现下标」；区别在于这里求的是**和大于 0**，而不是**和等于 0**。
