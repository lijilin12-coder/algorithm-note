# 链表删除

## 题目描述

给定一个单链表，删除第一个值等于给定值的节点，输出删除后的链表。

## 输入格式

第一行：以空格分隔的整数序列，以 `-1` 结尾，表示初始链表（`-1` 本身不计入链表）。

第二行：一个整数 $value$，表示要删除的值。若链表中存在值为 $value$ 的节点，删除
从头开始第一个符合条件的节点；若不存在这样的节点，链表保持不变。

## 输出格式

一行，删除后链表中所有元素，用空格分隔；若删除后链表为空，输出空行。

## 样例

输入：
```
1 2 3 -1
2
```

输出：
```
1 3
```

## 数据范围

- 链表长度 $0 \le n \le 1000$
- 节点值与待删除值 $-10^9 \le value \le 10^9$
