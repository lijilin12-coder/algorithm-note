# 分隔链表

来源：[LeetCode 86. 分隔链表](https://leetcode.cn/problems/partition-list/description/)

## 题目描述

给你一个链表的头节点 `head` 和一个特定值 `x`，请你对链表进行分隔，使得所有 **小于**
`x` 的节点都出现在 **大于或等于** `x` 的节点之前。

你应当 **保留** 两个分区中每个节点的初始相对位置。

## 示例 1

```
输入：head = [1,4,3,2,5,2], x = 3
输出：[1,2,2,4,3,5]
```

## 示例 2

```
输入：head = [2,1], x = 2
输出：[1,2]
```

## 提示

- 链表中节点的数目在范围 `[0, 200]` 内
- `-100 <= Node.val <= 100`
- `-200 <= x <= 200`

## 输入格式

第一行：以空格分隔的整数序列，表示链表 `head`，以 `-1` 结尾（`-1` 本身不计入链表）。

第二行：一个整数 `x`。

## 输出格式

一行，分隔后链表中所有元素，用空格分隔；若链表为空，输出空行。

## 样例

输入：
```
1 4 3 2 5 2 -1
3
```

输出：
```
1 2 2 4 3 5
```

## 数据范围

- 链表长度 `0 <= n <= 200`
- 节点值 `-100 <= Node.val <= 100`
- `-200 <= x <= 200`
