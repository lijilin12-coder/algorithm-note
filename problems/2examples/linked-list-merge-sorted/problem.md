# 合并两个有序链表序列

## 题目描述

给定两个按非递减顺序排列的单链表序列，请将它们合并为一个新的有序链表并输出。

你需要保持合并结果仍然是非递减顺序。

## 输入格式

共两行：

- 第一行：第一个有序序列，以 `-1` 结尾（`-1` 不属于序列）。
- 第二行：第二个有序序列，以 `-1` 结尾（`-1` 不属于序列）。

## 输出格式

输出一行，为合并后的有序序列，元素之间用一个空格分隔。

若合并后为空序列，输出空行。

## 样例

输入：
```
1 3 5 -1
2 4 6 -1
```

输出：
```
1 2 3 4 5 6
```

## 数据范围

- 两个序列长度分别为 `0 <= n, m <= 1000`
- 节点值范围：`-10^9 <= value <= 10^9`
