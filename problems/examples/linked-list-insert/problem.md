# 链表插入

## 题目描述

给定一个单链表，在指定位置插入一个新节点，输出插入后的链表。

## 输入格式

第一行：以空格分隔的整数序列，以 `-1` 结尾，表示初始链表（`-1` 本身不计入链表）。

第二行：两个整数 $pos$ 和 $value$，表示在第 $pos$ 个位置（从 1 开始计数）插入一个值
为 $value$ 的新节点。若原链表长度为 $n$，$pos$ 的合法范围是 $1 \le pos \le n+1$；
$pos = n+1$ 表示插入到链表末尾，$pos = 1$ 表示插入到链表头部。

## 输出格式

一行，插入后链表中所有元素，用空格分隔。

## 样例

输入：
```
1 2 3 -1
2 100
```

输出：
```
1 100 2 3
```

## 数据范围

- 链表长度 $0 \le n \le 1000$
- $1 \le pos \le n+1$
- 节点值与插入值 $-10^9 \le value \le 10^9$
