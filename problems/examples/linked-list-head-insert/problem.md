# 链表头插法：构建并追加

## 题目描述

给定一个空单链表，先读取一组整数并按输入顺序使用头插法插入链表；随后再读取一个整数 `x`，继续使用头插法将 `x` 插入链表头部，输出最终链表。

## 头插法说明

头插法是指：每次插入新节点时，都把新节点放在链表最前面（头结点之后）。

单次头插可以分为 3 步：

1. 创建新节点 `node`，保存要插入的值。
2. 令 `node->next = head->next`，让新节点先指向原来的第一个节点。
3. 令 `head->next = node`，把头结点指向新节点。

因此，若按顺序读入 `1 2 3` 并依次头插，最终链表为 `3 2 1`（输入顺序的逆序）。

## 输入格式

第一行：一个整数 `n`，表示初始需要插入的元素个数。

第二行：`n` 个整数，表示按顺序进行头插的元素。

第三行：一个整数 `x`，表示最后需要头插到链表头部的值。

## 输出格式

一行，输出最终链表中所有元素，元素之间用一个空格分隔。

## 样例

输入：
```
3
1 2 3
10
```

输出：
```
10 3 2 1
```

## 数据范围

- `0 <= n <= 1000`
- 节点值满足 `-10^9 <= value <= 10^9`
