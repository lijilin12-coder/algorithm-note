# 链表反转

给定一个单链表，请将链表中的节点顺序反转，并输出反转后的链表。

要求在原链表上完成反转，不要新建节点保存反转结果。

## 输入格式

一行：以空格分隔的整数序列，以 `-1` 结尾，表示输入链表；`-1` 本身不计入链表。

## 输出格式

一行，输出反转后的链表中所有元素，用空格分隔；若链表为空，输出空行。

## 样例

输入：
```
1 2 3 4 5 -1
```

输出：
```
5 4 3 2 1
```

## 数据范围

- 链表长度 $0 \le n \le 5000$
- 节点值 $-5000 \le value \le 5000$

## 思考

反转一个节点时，需要先保存它原来的后继节点，再让它指向前驱节点。你能否分别使用迭代和递归两种方法完成反转？
