# N 皇后（N-Queens）

> LeetCode: [51. N-Queens](https://leetcode.com/problems/n-queens/) / [51. N 皇后](https://leetcode.cn/problems/n-queens/description/)

## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n x n` 的棋盘上，并且使皇后
彼此之间不能相互攻击。

给你一个整数 `n`，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和
`'.'` 分别代表了皇后和空位。

## 输入格式

一行一个整数 `n`。

## 输出格式

第一行输出方案总数。

接下来依次输出每一种摆法：每种摆法占 `n` 行，每行是一个长度为 `n` 的字符串，
`Q` 表示皇后，`.` 表示空位；相邻两种摆法之间输出一个空行。

LeetCode 允许以**任意顺序**返回答案；本地测试的 `main` 会先把方案按
“第 0 行皇后所在列、第 1 行皇后所在列……”从小到大排序后再输出，
所以你的函数返回顺序不影响判题。

如果不存在合法摆法，只输出方案总数 `0`，不输出任何棋盘。

## 样例

样例 1：

输入：
```
4
```

输出：
```
2
.Q..
...Q
Q...
..Q.

..Q.
Q...
...Q
.Q..
```

解释：如上所示，4 皇后问题存在两个不同的解法。

样例 2：

输入：
```
1
```

输出：
```
1
Q
```

## 数据范围

- `1 <= n <= 9`

## 提示

- 按行递归：对第 `row` 行，依次尝试把皇后放在第 `0` 到 `n-1` 列，检查是否与
  之前已摆放的皇后冲突（同列，或 `|行差| == |列差|` 表示同对角线）。
- 用一个数组 `col[row]` 记录第 `row` 行皇后所在的列，方便检查冲突和最终输出。
- 摆满 `n` 行（`row == n`）时，说明找到一种合法摆法，把当前棋盘加入答案后继续
  回溯寻找下一种。
- 记得回溯：递归返回后要撤销当前行的摆放，尝试下一列。
