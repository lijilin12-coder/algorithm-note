# 飞机降落

> 来源：[洛谷 P9241 [蓝桥杯 2023 省 B] 飞机降落](https://www.luogu.com.cn/problem/P9241)

## 题目描述

有 `n` 架飞机准备降落到某个只有一条跑道的机场。其中第 `i` 架飞机在 `t_i` 时刻
到达机场上空，到达时它的剩余油料还可以继续盘旋 `d_i` 个单位时间，即它最早可以
于 `t_i` 时刻开始降落，最晚可以于 `t_i + d_i` 时刻开始降落。降落过程需要 `l_i`
个单位时间。

一架飞机降落完毕时，另一架飞机可以立即在同一时刻开始降落，但是不能在前一架
飞机完成降落前开始降落。

请你判断 `n` 架飞机是否可以全部安全降落。

## 输入格式

输入包含多组数据。

第一行包含一个整数 `T`，代表测试数据的组数。

对于每组数据，第一行包含一个整数 `n`。

以下 `n` 行，每行包含三个整数 `t_i d_i l_i`。

## 输出格式

对于每组数据，输出一行 `YES` 或者 `NO`，代表是否可以安排 `n` 架飞机全部安全
降落。

## 样例

输入：
```
2
3
0 100 10
10 10 10
0 2 20
3
0 10 20
10 10 20
20 10 20
```

输出：
```
YES
NO
```

【样例说明】

对于第一组数据，可以安排第 3 架飞机于 0 时刻开始降落，20 时刻完成降落；安排
第 2 架飞机于 20 时刻开始降落，30 时刻完成降落；安排第 1 架飞机于 30 时刻开始
降落，40 时刻完成降落。

对于第二组数据，无论如何安排，都会有飞机不能及时降落。

## 数据范围

- `1 <= T <= 10`
- `1 <= n <= 10`
- `0 <= t_i, d_i, l_i <= 100000`

## 提示

- `n` 很小（不超过 10），可以用回溯法枚举「降落顺序」：每一步从尚未降落的飞机
  中选一架，检查它能否在当前跑道空闲时刻之后按时降落，可以就选它降落、更新
  跑道空闲时刻、递归处理下一步，行不通就撤销选择换下一架（回溯）。
- 某架飞机能在「当前时刻」`cur` 降落，需要满足 `cur <= t_i + d_i`（还没超过
  它能撑到的最晚时刻）；实际开始降落的时刻是 `max(cur, t_i)`，降落完成后跑道
  空闲时刻更新为 `max(cur, t_i) + l_i`。
- 记得每组数据之间要清空/重置状态（比如标记哪些飞机已经降落的数组）。
- 一旦某组数据找到一种可行方案就可以提前结束搜索，不必穷举所有排列。
