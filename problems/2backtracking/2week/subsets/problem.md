# 子集

## 题目描述

给定一个含 `n` 个互不相同整数的数组 `nums`，请你用回溯法求出它的所有子集
（幂集），并按照下面规定的顺序输出。数组不保证有序。

## 输入格式

第一行一个整数 `n`。

第二行 `n` 个整数，即 `nums`，用空格分隔。

## 输出格式

第一行输出子集总数（应为 `2^n`）。

接下来按照“从下标 `0` 开始，每次要么把当前下标的元素加入路径继续向后递归，
要么跳过它”的回溯顺序输出每一个子集：具体来说，进入某个下标区间时先输出当前
路径对应的子集，再依次尝试把后面尚未选择的元素加入路径递归下去（即先输出父
集合，再输出由它扩展出的子集）。

每个子集占一行，格式为：子集大小 `k`，后面跟 `k` 个元素（保持它们在 `nums`
中原本的先后顺序），用空格分隔。空集只输出 `0`。

## 样例

输入：
```
3
1 2 3
```

输出：
```
8
0
1 1
2 1 2
3 1 2 3
2 1 3
1 2
2 2 3
1 3
```

## 数据范围

- `1 <= n <= 10`
- `-10 <= nums[i] <= 10`
- `nums` 中所有元素互不相同

## 提示

- 用 `path` 保存当前已选择的元素，递归函数 `backtrack(start)` 表示"下一个可以
  考虑的下标是 `start`"。
- 每次进入 `backtrack(start)` 时，先把当前 `path` 作为一个子集输出（包括空
  路径，对应空集）。
- 然后用一个循环，让 `i` 从 `start` 到 `n-1`：把 `nums[i]` 加入 `path`，递归
  调用 `backtrack(i + 1)`，再把 `nums[i]` 从 `path` 中移除（回溯）。
