# 五子棋和棋计数（小棋盘版）

> 原题来源：[洛谷 P10386 [蓝桥杯 2024 省 A] 五子棋对弈](https://www.luogu.com.cn/problem/P10386)
> （原题是 `15 x 15` 棋盘的“结果填空题”，只需要提交一个整数答案，且这个整数
> 大到需要专门的算法和长时间计算才能求出。这里把棋盘大小改成参数 `N`，方便你
> 用较小的棋盘练习和验证算法。）

## 题目描述

小蓝（白棋）和小桥（黑棋）在一个 `N x N` 的棋盘上下五子棋，规则如下：

1. 棋盘共有 `N * N` 个格子。
2. 白棋先手，之后双方轮流落子，每次恰好放一枚棋子，直到棋盘被下满为止。
3. 若某一方在横线、竖线或两个方向的斜线上，最先形成 **连续 5 个同色棋子**，
   则该方获胜，游戏立刻结束。
4. 如果棋盘被下满（`N * N` 个格子都有棋子）时仍未分出胜负，则视为平局（和棋）。

因为白棋先落子，当棋盘下满时，白棋恰好比黑棋多下一子（如果 `N * N` 是奇数）
或者两人下子数相同（如果 `N * N` 是偶数）；也就是说，白棋总共下了
`ceil(N * N / 2)` 枚棋子，黑棋总共下了 `floor(N * N / 2)` 枚棋子。

现在给定 `N`，请你计算：有多少种不同的**终局棋盘**（每个格子都填有黑棋或白棋，
白棋数量为 `ceil(N * N / 2)`，黑棋数量为 `floor(N * N / 2)`），使得整局比赛
以和棋收场（也就是这个棋盘里，黑棋和白棋都没有连续 5 个同色棋子连成一线）。

终局棋盘相同、只是落子顺序不同的情况算作同一种；终局棋盘不同则算作不同的
情况。

## 输入格式

第一行一个整数 `T`，表示测试数据组数。

接下来 `T` 行，每行一个整数 `N`，表示棋盘边长。

## 输出格式

对每组数据输出一行，表示满足条件的终局棋盘数量。

## 样例

输入：
```
5
1
2
3
4
5
```

输出：
```
1
6
126
12870
3126376
```

【样例说明】

- 当 `N <= 4` 时，棋盘上任何一条直线（横、竖、斜）的长度都不超过 4，不可能
  连成 5 子，所以任何一种黑白棋子数量满足要求的填法都算和棋，答案就是从
  `N*N` 个格子中选出 `ceil(N*N/2)` 个格子放白棋的方案数，即组合数
  `C(N*N, ceil(N*N/2))`。例如 `N=3` 时为 `C(9,5) = 126`。
- 当 `N = 5` 时，只有 5 条横线、5 条竖线和 2 条主对角线恰好长度为 5，需要排除
  这 12 条线中任意一条被同一种颜色占满的情况。

## 数据范围

- `1 <= T <= 20`
- `1 <= N <= 5`（原题的 `N = 15`，但答案大到需要专门的高效算法和很长的计算
  时间才能求出，这里限定较小的 `N` 方便你验证算法正确性）

## 提示

- 这是一道「计数」而不是「判断可行性」的题，思路是回溯法枚举棋盘：按格子
  顺序（比如逐行逐列）依次决定每个格子放黑棋还是白棋，凑够白棋数量后剩下的
  格子只能放黑棋（或者反过来），每凑出一种完整的棋盘就检查一次是否合法，
  合法就计数加一。
- 更高效的做法是**边填边判断、提前剪枝**：每放一个棋子，就检查它所在的横线、
  竖线、两条斜线上，从它开始往回数的同色连续个数是否达到了 5；一旦某一步
  就已经形成了 5 连子，这一分支后面无论怎么填都不可能是和棋，可以直接剪掉，
  不用等到填满整个棋盘才发现不合法。
- 判断“连续同色”时要注意棋盘边界，以及己方棋子数量是否已经用完（用完了这一
  格就只能放另一种颜色）。
- 为什么只需要检查**终局**棋盘是否有 5 连子，而不用真正模拟每一步落子的
  先后顺序？（提示：如果终局里没有任何 5 连子，那么下棋过程中的任何一个
  中间状态也不可能出现过 5 连子——因为连续子的长度只会随着落子增加，不会
  减少。）
