# 翻硬币

> 原题来源：[AcWing 1208. 翻硬币](https://www.acwing.com/problem/content/description/1210/)

## 题目描述

桌上放着排成一排的若干硬币，用 `*` 表示正面，用 `o`（小写字母，不是数字
`0`）表示反面。

比如可能的情形是：`**oo***oooo`

如果同时翻转左边的两个硬币，则变为：`oooo***oooo`

每次操作只能同时翻转**相邻**的两个硬币，问从给定的初始状态变为给定的目标
状态，最少需要多少步操作？数据保证答案一定有解。

## 输入格式

两行等长的字符串，分别表示初始状态和目标状态。

## 输出格式

一个整数，表示最少操作步数。

## 样例

输入 1：
```
**********
o****o****
```

输出 1：
```
5
```

输入 2：
```
*o**o***o***
*o***o**o***
```

输出 2：
```
1
```

## 数据范围

- 输入字符串的长度均不超过 `100`。
- 数据保证答案一定有解。

## 提示

- 从左到右贪心处理：如果第 `i` 个位置（下标从 0 开始）当前状态和目标状态不
  一致，就翻转第 `i、i+1` 两个硬币，操作次数加一；处理到倒数第二个位置为
  止（最后一个位置不能再往右翻，只能靠前面的操作把它顺带翻对）。
- 为什么这样贪心是对的：处理到位置 `i` 时，前面 `0..i-1` 的位置都已经和目标
  状态一致了。如果这一步不翻转位置 `i`，那么位置 `i` 以后再也没有操作会碰到
  它（因为每次只能翻相邻两个，而我们是从左到右依次处理，不会回头翻已经处理
  过的位置），所以只要第 `i` 位不一致，就必须、也只能在这一步翻转它。
- 用一个和输入等长的字符数组（或直接在字符串上原地修改）保存当前状态，翻转
  就是把这两个位置的字符做 `*`/`o` 互换。
