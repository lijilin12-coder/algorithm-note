# 目标和（Target Sum）

> LeetCode: [494. Target Sum](https://leetcode.com/problems/target-sum/) / [494. 目标和](https://leetcode.cn/problems/target-sum/)

## 题目描述

给你一个非负整数数组 `nums` 和一个整数 `target`。

向数组中的每个整数前添加 `'+'` 或 `'-'`，然后串联起所有整数，可以构造一个**表达式**：

- 例如，`nums = [2, 1]`，可以在 `2` 之前添加 `'+'`，在 `1` 之前添加 `'-'`，然后串联起来
  得到表达式 `"+2-1"`。

返回可以通过上述方法构造的、运算结果等于 `target` 的不同**表达式**的数目。

## 输入格式

第一行两个整数 `n` 和 `target`，用空格分隔，分别表示数组长度和目标值。

第二行 `n` 个整数，用空格分隔，表示数组 `nums`。

## 输出格式

一行一个整数：运算结果等于 `target` 的不同表达式的数目。

## 样例

样例 1：

输入：
```
5 3
1 1 1 1 1
```

输出：
```
5
```

解释：一共有 5 种方法让最终目标和为 `3`：
```
-1 + 1 + 1 + 1 + 1 = 3
+1 - 1 + 1 + 1 + 1 = 3
+1 + 1 - 1 + 1 + 1 = 3
+1 + 1 + 1 - 1 + 1 = 3
+1 + 1 + 1 + 1 - 1 = 3
```

样例 2：

输入：
```
1 1
1
```

输出：
```
1
```

## 数据范围

- `1 <= nums.length <= 20`
- `0 <= nums[i] <= 1000`
- `0 <= sum(nums[i]) <= 1000`
- `-1000 <= target <= 1000`

## 提示

- 每个数只有 `+` / `-` 两种选择，最直接的做法是回溯，复杂度 `O(2^n)`。
- 回溯的状态是 `(i, 当前和)`，存在重叠子问题，可以加备忘录。
- 进一步思考：设加 `+` 的数之和为 `P`，加 `-` 的数之和为 `N`，能否把问题转化成
  一个**背包**问题？注意 `nums[i]` 可能为 `0`。
