# 动态规划

## 基本思路

动态规划（DP）用于求解具有**重叠子问题**和**最优子结构**的问题：

1. 定义状态：`dp[i]` 表示什么。
2. 找到状态转移方程：`dp[i]` 由哪些更小的子问题推出。
3. 确定 base case（边界条件）。
4. 确定遍历顺序，自底向上填表（或带备忘录自顶向下递归）。

## 完全背包（无限次使用某个物品）

零钱兑换属于**完全背包**模型：每种硬币可以使用无限次，求凑出目标金额所需的
最少硬币数。

设 `dp[j]` 表示凑出金额 `j` 所需的最少硬币数，则：

$$
dp[j] = \min_{c \in \text{coins}, c \le j} \big(dp[j-c] + 1\big)
$$

base case：`dp[0] = 0`（凑出金额 0 不需要任何硬币）。

与 0/1 背包（每个物品只能用一次）的区别在于内层遍历方向：完全背包中金额
`j` 从小到大遍历即可允许同一枚硬币被重复选取。
