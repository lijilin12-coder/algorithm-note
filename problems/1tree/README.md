# 二叉树

1. ## 学习计划

- [二叉树基础及常见类型](https://labuladong.online/zh/algo/data-structure-basic/binary-tree-basic/)   只需要重点学 二叉树概念和C语言实现就好了，其他部分用到了再仔细学。
  - 树的定义，理解什么是父节点，叶子结点。
  - 完全二叉树和满二叉树了解
  - 二叉树的实现方式。 重点学
  - 其他内容可以简单了解一下。
- [二叉树的递归/层序遍历](https://labuladong.online/zh/algo/data-structure-basic/binary-tree-traverse-basic/)  重点学。并且完成LeetCode的相关题。

- 先序/中序/后续都是递归类型的。可以直接学
- 层序遍历会借助队列，可以先学习：
  - [队列/栈基本原理](https://labuladong.online/zh/algo/data-structure-basic/queue-stack-basic/)
  - [用链表实现队列/栈](https://labuladong.online/zh/algo/data-structure-basic/linked-queue-stack/)
  - [常用数据结构](https://labuladong.online/zh/programming-language/cpp/data-structures/#:~:text=%C2%B6-,%E9%98%9F%E5%88%97%20queue,-%E9%98%9F%E5%88%97%E6%98%AF%E5%85%88%E8%BF%9B%E5%85%88%E5%87%BA)，C++ STL内置的 queue （和vector差不多）。这样就可以用现成的，而不是从头开始写
- [DFS 和 BFS 的适用场景](https://labuladong.online/zh/algo/data-structure-basic/use-case-of-dfs-bfs/)  重点学。完成相关的题，不会做也没关系， 可以看解答然后自己再写。
- [多叉树的递归/层序遍历](https://labuladong.online/zh/algo/data-structure-basic/n-ary-tree-traverse-basic/)  重点学，完成相关的习题。
- [回溯算法解题套路框架](https://labuladong.online/zh/algo/essential-technique/backtrack-framework-2/)    然后就可以开始继续学习回溯了。
