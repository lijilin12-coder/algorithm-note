# N 叉树的后序遍历

> LeetCode: [590. N-ary Tree Postorder Traversal](https://leetcode.com/problems/n-ary-tree-postorder-traversal/) / [590. N 叉树的后序遍历](https://leetcode.cn/problems/n-ary-tree-postorder-traversal/)

## 题目描述

给定一个 N 叉树的根节点 `root`，返回其节点值的**后序遍历**结果（按顺序依
次递归遍历每一个子树，最后访问根节点）。

## 输入格式

一行，按层序（BFS）排列、用空格分隔的若干个 token；每个节点的子节点列表前
都会有一个 `null` 作为分隔（即使这个节点没有子节点）：

- 第一个 token 是根节点的值；
- 依次处理队列中的每个节点：先跳过一个 `null`（表示这个节点的子节点列表开
  始），再读取若干个整数作为它的子节点值，直到遇到下一个 `null` 为止（这个
  `null` 属于下一个节点，不在这里消耗）。

如果根节点为空，输入是一个空行（不包含任何 token）。

例如树

```
        1
     /  |  \
    3   2   4
   / \
  5   6
```

对应输入 `1 null 3 2 4 null 5 6`。

## 输出格式

一行，依次输出后序遍历得到的节点值，用空格分隔；如果树为空，输出空行。

## 样例

输入：
```
1 null 3 2 4 null 5 6
```

输出：
```
5 6 3 2 4 1
```

## 数据范围

- 节点总数在范围 `[0, 10000]` 内
- `0 <= Node.val <= 10000`
- N 叉树的高度不超过 `1000`

## 提示

- 后序遍历的顺序是：按从左到右的顺序，依次对每一个子节点递归做同样的事
  情，全部子树都访问完之后，最后才访问根节点自己的值。
- 你能否分别用递归和迭代（借助栈）两种方式实现？
